# Promotion Checklist

## Dev Gate
- CI build/test/scan passed.
- Smoke tests passed.
- Migration dry-run completed.

## Staging Gate
- Dev gate passed.
- Integration tests passed.
- Parity checks passed for targeted module.
- Performance baseline acceptable.

## Production Gate
- Staging gate passed.
- Approval checkpoint completed.
- Rollback package verified.
- On-call readiness confirmed.
